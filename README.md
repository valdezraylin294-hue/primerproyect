# primerproyect
Sistema básico de supermercado desarrollado en Python como proyecto de aprendizaje.

Este proyecto consiste en un sistema básico de supermercado desarrollado en Python, creado como parte de mi proceso de aprendizaje y práctica en programación. El programa simula algunas operaciones de un supermercado, como la búsqueda de productos, gestión del carrito de compras, compra de productos, control de inventario y registro del total de ventas. Para desarrollarlo puse en práctica conceptos fundamentales de Python, como ciclos while, condicionales, listas, métodos, variables, contadores y manejo de entradas de datos. Este proyecto representa una de mis primeras experiencias construyendo un programa desde cero y forma parte de mi crecimiento y evolución como programador. Actualmente, el proyecto se encuentra en proceso de mejora y seguirá recibiendo cambios y nuevas funcionalidades a medida que continúe aprendiendo Python.
